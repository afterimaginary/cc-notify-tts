# Decisions

Each file here records one decision or measured result, numbered in the order the work was planned and referred to as `ADR-NNNN`. Its front matter gives the decision in one sentence and its status.

Some numbers have no file: 0008, 0010, 0024, 0027, 0028, 0031, 0032 and 0035. Each was reserved for a piece of work when it was planned, and the work turned out not to need a decision of its own. The numbers aren't reused, so a reference to an ADR always means the same record.
